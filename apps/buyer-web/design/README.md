# 新买家站设计稿（WS8）

状态：**待协调者审阅冻结**。冻结后 WS11～WS13 以本目录为准；改稿在本目录改旧文件，不另开版本。

## 怎么看

浏览器打开 `index.html`：每页左侧手机（390 宽）、右侧 PC（1280 宽，缩放 75%）。`pages/*.html` 是同一份响应式页面，断点用真实媒体查询（与 Tailwind / Nuxt UI 默认一致：`md` 768、`lg` 1024），可以直接拖窗口看过渡。截图在 store `media/p9/ws8-design/`（`NN-页名-m.png` / `-pc.png`）。

- 颜色只引用品牌令牌 `shop/lilishop-ui/brand/theme.css` 的 `--lr-*`；中性色（正文二三级、分隔线、浅底）由夜航墨与白混合得到，不写色值。状态色不用红绿：进行中用漫游青，需注意用日出橙文字版，结束用中性灰。
- 字体：系统字体栈，PingFang SC / Noto Sans SC 优先，数字等宽；不从远程字体服务加载。
- 图标：`kit.js` 里是示意线稿，实现用 lucide 同名图标（`@iconify-json/lucide` 本地打包）。
- 目的地用两字母代码圆标（区域与全球用夜航墨底、日光黄字），不用旗帜图与 emoji。
- 橙色虚线框与小字为设计标注，只说明数据来源与分支，不进实现。

## 信息架构与路由

手机：底部四个标签「选卡 / 我的卡 / 帮助 / 我的」，下单与详情页换成顶部返回栏，并在底部固定操作条。PC：顶栏「选目的地 / 我的卡 / 订单 / 帮助中心」加右侧账户，底部深色页脚。

| 稿 | 页面 | 路由 | 渲染 | 主要数据 |
|----|------|------|------|----------|
| 01 | 首页 | `/` | SSR + 短时缓存 | K3 目的地列表（`hot`、`kind`、`fromPriceFen`） |
| 02 | 全部目的地与搜索 | `/esim` | SSR | K3 `?q=`（中文、拼音、英文别名；搜国家同时列出覆盖它的多国套餐） |
| 03 | 目的地页 | `/esim/[code]` | SSR + 短时缓存 | K3 `destinations/{code}/plans`（天数分段、形态与能力筛选） |
| 04 | 套餐详情 | `/esim/[code]/[skuId]` | SSR | K3 套餐字段 + 使用区域说明接口 |
| 05 | 登录 | `/login` | 客户端 | buyer-api 短信 / 密码登录；微信内授权登录由开关打开 |
| 06 | 确认订单 | `/checkout` | 客户端 | 立即购买 + 数量；实名须知（`kycRequired`）；地址（实体卡）；按终端列支付方式 |
| 07 | 支付 | `/pay/[sn]` | 客户端 | 壳收银台；PC 微信扫码、手机从支付应用返回的等待态，轮询支付状态 |
| 08 | 支付结果 | `/pay/result` | 客户端 | 轮询 `/buyer/liroam/cards` 交码进度 |
| 09 | 我的卡 | `/cards` | 客户端 | 卡投影列表、到期提醒（notifications）；使用中 / 待安装 / 配送中 / 已结束 |
| 10 | 卡详情与安装 | `/cards/[id]` | 客户端 | 二维码与 SM-DP+ / 激活码、iPhone / 安卓分步、用量、套餐记录；实名、物流、软卡写卡按卡型替换安装区 |
| 11 | 加包 | `/cards/[id]/topup` | 客户端 | 只列这张卡可用的加包 SKU（选卡意图） |
| 12 | 申请退款与进度 | `/cards/[id]/refund` | 客户端 | 整卡或单个加包；状态含「退款中」（K6）；渠道卡不出整卡退款 |
| 13 | 我的订单 | `/orders` | 客户端 | buyer-api 订单 |
| 14 | 订单详情 | `/orders/[sn]` | 客户端 | 订单 + 卡区块（K4 `cards?orderSn=`） |
| 15 | 帮助中心 | `/help` | SSR | 壳文章分类与文章；客服方式为运营配置 |
| 16 | 设备兼容 | `/help/devices` | SSR | 壳文章（机型清单由运营维护） |
| 17 | 帮助文章 | `/help/[id]` | SSR | 壳文章 |
| 18 | 我的 | `/account` | 客户端 | 资料、消息、地址、安全；我的佣金只对分销员显示 |
| 19 | 认领渠道订单 | `/account/claim` | 客户端 | 渠道认领接口 |
| 20 | 我的佣金 | `/account/commission` | 客户端 | 佣金台账、提现申请与记录、推广链接 |
| 21 | 空态、异常与抽屉 | — | — | 无卡、搜不到、404、功能未开放（K1）、网络异常、加载骨架、筛选抽屉 |

不做的入口：购物车、店铺、优惠券、秒杀、积分、评价、收藏、足迹、礼品卡（集成方案 §2.5）。

## 组件对应（Nuxt UI 4）

| 设计稿 | Nuxt UI |
|--------|---------|
| 页头、标签栏、页脚 | `UHeader`、自写标签栏（固定底部）、`UFooter` |
| 目的地搜索与联想 | `UInputMenu`（服务端搜索） |
| 天数分段、tabs | `UTabs` |
| 筛选 chip | `UButton` 的 `variant` 切换；手机筛选为 `UDrawer`，PC 为 `UModal` |
| 套餐卡片、目的地块、卡片 | `UCard` + 自有组件 `PlanCard`、`DestinationTile`、`SimCard` |
| 状态徽标、标签 | `UBadge` |
| 剩余量 | `UProgress` |
| 安装步骤、退款 / 交码进度 | `UStepper` 或 `UTimeline` |
| 表单 | `UForm` + zod、`UInput`、`UPinInput`（验证码）、`UInputNumber`（数量）、`URadioGroup` |
| 提示条 | `UAlert` |
| 骨架 | `USkeleton` |

主题：`app.config.ts` 的 `ui.colors.primary` 指向由令牌生成的色阶；`main.css` 把 `--ui-primary` 设为 `var(--lr-primary)`、`--ui-text` 设为 `var(--lr-ink)`，只开浅色模式。
